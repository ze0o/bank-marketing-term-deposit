# Data

`bank-full.csv`: 45,211 rows × 17 columns, comma-separated.

**Source:** UCI Machine Learning Repository, *Bank Marketing* dataset
(Moro, Cortez & Rita, 2014), https://archive.ics.uci.edu/dataset/222/bank+marketing

Direct-marketing phone campaigns of a Portuguese bank. Each row is one client contact; the target `y`
says whether the client subscribed to a term deposit. See `notebooks/01_data_overview.ipynb` for the
full data dictionary.
